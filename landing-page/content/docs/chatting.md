The web app and Telegram reach the same agent. Use whichever is in front of you. This
page is about the web app, which shows more of what is going on.

## The chat

Type, press enter. The reply streams in a word at a time. Underneath it you get three
numbers: tokens in, tokens out, and what that reply cost in dollars. The header totals
the whole session.

It is how you notice a conversation has grown expensive, and when to start a new one.

## Attachments

The clip button takes up to **four files per message**. What the agent can do with them
depends on which capabilities are on:

- Photos and screenshots need **Image input**, and a model that can see.
- PDFs, spreadsheets, CSVs, code and plain text need **File ingest**.
- Voice notes and audio files need **Audio input**.

Large images are shrunk in your browser before they are sent, so a photo straight off a
phone does not cost you an upload. The ceilings are in
[Files, photos and voice notes](/docs/files-and-media).

## Voice

Hold the microphone button and talk. Recording stops on its own after ten minutes. The
clip is transcribed once, when it arrives, and the agent works from the transcript. A
voice note costs about the same as typing the same thing.

## Stopping a reply

**Stop** cancels a reply in progress. What was already written is kept, and so is its
cost: those tokens were generated whether or not you wanted the rest of them. Use it on
a wandering answer to save money.

## Retrying and forking

Every one of your messages can be **forked**. Forking takes everything up to that point
into a brand new session and puts your question back in the composer, ready to be
rewritten.

Use it when a conversation goes wrong. Arguing the agent back on track keeps the bad
turn in the history and pays for it again on every message that follows. Fork above
the mistake and ask a better question instead.

## Sessions in the sidebar

The left sidebar lists every conversation this agent has, web and Telegram alike. You
can search them, rename them, and delete the ones you are done with. Sessions are named
automatically from their first few messages, so the list stays readable without you
doing anything.

## Reading a Telegram chat here

Telegram conversations appear in the same list. Open one to read the transcript, see
what each reply cost, and carry on typing from here. The person on Telegram sees your
agent's replies as normal.
